# 答题纸与踩分点自查表（模板）

> 用途：做题时按框填，做完按表自查。核心目的只有一个——让"答了几点"变成可见的动作，而不是凭感觉写满。

---

## 一、答题前：30 秒定三件事

| 三问 | 我的答案 |
|---|---|
| 这是什么题型？（概括 / 赏析 / 作用 / 含义 / 分析 / 探究） | |
| 分值是几分？该答几点？（2 分→1-2 点；3 分→2-3 点；4 分→2-4 点；5 分以上→3-5 点） | |
| 答案在原文哪一段？（写下起止位置） | |

---

## 二、分题型答题框

### 1. 概括题
- 谁：
- 在什么情况下：
- 做了什么：
- 结果：

### 2. 赏析题（四层，缺一扣一）
- 手法：
- 写出了什么（具体内容，不能只写"生动形象"）：
- 效果（突出对象的什么特点 / 人物什么心理）：
- 情感：

### 3. 作用题
- 结构作用：
- 内容作用：
- 情感或主题作用：

### 4. 含义题
- 表层义：
- 深层义：
- 情感或指向：

### 5. 人物形象
- 特征 1：　　依据（原文情节或描写）：
- 特征 2：　　依据：

### 6. 文言翻译
- 得分点 1（实词 / 活用 / 句式）：
- 得分点 2：
- 整句通顺检查：□

### 7. 开放探究
- 观点（一句）：
- 文本依据（一句 + 出处）：
- 联系实际（一句）：

---

## 三、答题后：自查五项（逐项打勾，缺项当场补）

- □ 分点了，每点一行，标了序号
- □ 点数与分值匹配（4 分题至少 2 点，最好 3 点）
- □ 用了学科术语，不是口语（"铺垫""照应""烘托"，而非"写得很好"）
- □ 每个判断都有文本依据（引了原文或指向具体段落）
- □ 没有把"作用"答成"内容"、把"含义"答成"赏析"

---

## 四、错题归因（每题只归一类主因）

| 题号 | 题型 | 我答了几点 | 该答几点 | 缺哪一层 | 主因 |
|---|---|---|---|---|---|
| | | | | | 规范 / 方法 / 知识 / 理解 |
| | | | | | |
| | | | | | |

**归因规则**：

- 缺层发生在"点数不够""没分点""没用术语"→ **规范类**（改得最快）
- 不知道这类题该走什么步骤 → **方法类**
- 该背的没记住 → **知识类**
- 读懂了表面，没读出深层 → **理解类**（最后处理）

## 五、每周小结（只写三行）

1. 本周错得最多的题型：
2. 这一类题我缺的是哪一层：
3. 下周只练这一个点，做 ___ 题。
