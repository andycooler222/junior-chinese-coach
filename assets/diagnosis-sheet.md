## 三、失分归因（四类，勾选为主）

同一道错题可能同时属于两类，按主因归类。

| 类型 | 特征 | 是否命中 | 涉及分值 |
|---|---|---|---|
| 规范类 | 会做但没按规矩答：不分点、缺术语、点数少于分值 | □ | |
| 方法类 | 不知道这类题该走什么步骤 | □ | |
| 知识类 | 该记的没记住：字词、默写、实词、常识 | □ | |
| 理解类 | 读懂了表面，没读出深层或情感 | □ | |

**判定规则**：规范类与方法类优先处理，一次训练可改；知识类靠日常积累，拆成每日 10 分钟；理解类最后处理，需要长期阅读量。

## 七、给家长的三条提醒

1. **本单只解决一个能力点。** 看到其他问题先记下来，不要当场追加。
2. **不要替他改句子、给答案。** 卡住时只问："你打算先写哪一句？" 让他自己动笔。
3. **不要看分数看点数。** 复测只看"答了几点、该答几点"，分数波动一周内没有意义。
