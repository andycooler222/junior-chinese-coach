# 写作：三遍改法与诊断维度

## 前提

上海中考语文 150 分，作文 60 分，要求不少于 600 字，以命题、半命题为主，可能出现提示语或材料，文体默认记叙文。

### 评分结构（三项，合计 60）

**中心与材料 25 + 语言 25 + 思路与结构 10**。部分资料表述为"内容 25 + 表达 25 + 发展等级 10"，维度名不同，分值骨架一致。

| 档 | 分值 | 基准分 | 特征 |
|---|---|---|---|
| A 一类 | 53–60 | 56 | 切合题意、中心突出；选材恰当有新意、感情真挚、内容充实；语言流畅有表现力；思路通畅、详略得当 |
| B 二类 | 43–52 | 47 | 符合题意、中心明确；选材恰当、感情真实；语言通顺；结构完整 |
| C 三类 | 33–42 | 36 | 基本符合题意；内容单薄、选材普通；语病较多、详略不当 |
| D 四类 | 24–32 | 27 | 偏离题意、内容空洞、结构混乱 |
| E 五类 | 0–23 | — | 严重偏题、抄袭、字数严重不足 |

三条硬规则：不足 600 字降档；套作或背范文压档；错别字与卷面在语言项内扣分。

**三项里最拉分的是"中心与材料 25 分"**，对应审题与立意。审题偏了，语言再好也压到三类以下。所以本文件的第一轮永远是审题与结构，不是语言。

本文件不预测分数，只给可操作的诊断维度。

核心主张：**一篇作文改三遍，胜过写三篇不改。** 三遍分别对应三个评分维度，一轮只改一样。一次改三样，是白改的主因。

---

## 一、审题：三步定位

1. **抓题眼**：题目里最不能替换的那个词。《这里也有乐趣》的题眼是"也"（隐含"别人觉得没有"），不是"乐趣"。
2. **辨限定**：时间（"那一刻""这一天"）、地点（"这里"）、人称（"我们""我"）、数量（"一件""一次"）。
3. **明范围**：写人、写事、写景、写理。范围错了，语言再好也降档。

审题诊断只问一句："这道题如果换掉哪个词，你的作文就不成立了？"答不出来，就是没审清。

---

## 二、立意：看清停在哪一层

| 层 | 表现 | 判断 |
|---|---|---|
| 一 | 只把事情讲完 | 及格线附近 |
| 二 | 事情加一句"我明白了……" | 常见档，容易空喊 |
| 三 | 从"这件事"走到"这类事"，有普遍性 | 中上 |
| 四 | 有"我"的位置：我的局限、我的变化、我的选择 | 高分段的共同点 |

诊断方法：让孩子用一句话说出"这篇到底想讲什么"。说不出，或说出的是口号，说明立意没落地。**注意：这一句必须他自己说，不能替他写。**

---

## 三、结构：段落功能表

第一轮只做这件事。逐段填表，填不出来或填出"过渡段"以外的空白，就是结构问题。

| 段落 | 写了什么 | 承担什么功能 | 是否必要 |
|---|---|---|---|
| 1 | | 入题 / 设悬念 / 交代场景 | |
| 2 | | 起因 | |
| 3 | | 经过（详写） | |
| 4 | | 转折点（详写） | |
| 5 | | 结果 | |
| 6 | | 点题 / 升华 | |

四条判断标准：

1. 每段能否一句话说清作用（说不出 = 该删或该并）
2. 详写是否落在"发生变化"的那一段（多数孩子详写开头，写景写人，恰恰最不该详）
3. 段与段之间有没有衔接（时间词、动作延续、情绪递进）
4. 首尾是否扣题（不是首尾相同，而是同一件事的两个阶段）

---

## 四、语言：五处追问，不给改写句

第二轮只挑 5 处最需要改的地方，每处给一个追问。追问是这一步唯一允许的输出形式。

| 症状 | 追问 |
|---|---|
| 情绪词直接给结论（"我很紧张"） | 当时你身体的哪个部位最先有反应？手、喉咙、还是腿？ |
| 形容词堆砌（"美丽极了""非常开心"） | 如果删掉"非常、很、十分"，这句话还剩下什么？ |
| 概括代替细节（"我们玩得很开心"） | 那天你们具体做了哪三件事？挑一件说细一点。 |
| 长句一口气到底 | 这句话里有几个动作？能不能拆成两句，一句一个动作？ |
| 通篇一个节奏 | 全文有没有一处短句？短句放在哪最有力？ |

这三条不许做：不许给改写后的句子、不许用"建议改为"、不许示范。

---

## 五、灵魂：三个问题

第三轮只谈两件事——这篇想说什么，结尾有没有说出来。

1. 这件事让你对什么改变了看法？（不是"懂得了要努力"，而是具体到某个人的某个举动）
2. 如果重来一次，你会怎么做？为什么？
3. 你希望读者记住哪一句？这句必须是你自己想出来的，不是抄来的金句。

结尾诊断只看一条：**这段是在"总结事情"，还是在"说出认识"？** 前者是收尾，后者才是升华。喊口号（"让我们一起努力吧"）不算升华，算扣分项。

---

## 六、复批：只评变化

把改前、改后并列，逐处对比。输出三列：

| 位置 | 改前的问题 | 改后是否真的变好（依据） |
|---|---|---|

两个必须指出的情况：

- **改了但没变好**：为改而改、越改越绕、改掉了原来的细节。这一项最容易被忽略，但不指出来，孩子会形成"改就是好"的错觉。
- **该改没改**：诊断过但仍未动的段落，说明还没理解问题在哪，需要回到对应轮次重讲。

---

## 七、六类常见失分

按出现频率排序，做诊断时直接对号：

1. **审题偏**：题眼没抓住，写成了另一个题目。属于最致命的一类，语言再好也救不回。
2. **流水账**：从早到晚全写，没有详略，没有一件事被写透。
3. **空泛抒情**：通篇"我很感动""我明白了"，没有一处具体动作或场景。
4. **结构断裂**：段与段各说各的，靠"后来""然后"硬接。
5. **结尾拔高生硬**：事件本身支撑不住那句大道理。
6. **语言堆砌**：形容词、排比、比喻滥用，读起来满，实际没有信息。

前两条改起来最快（一两篇就能纠正），第 3、6 条需要较长训练周期。诊断排序时优先选"改得快、失分多"的那条。

---

## 八、素材：一材三用

不建议大量收集素材本。做法是：把一个真实经历拆出三个角度——发生了什么（事）、我当时的反应（人）、后来怎么看（理）。同一件事可以应付"成长类""亲情类""选择类"三类题目。

判断素材够不够用，只看一条：**能不能说出三个细节。** 说不出三个细节的素材，写出来一定是空泛的。
