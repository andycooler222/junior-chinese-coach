# 名著导读：考点卡与复习法

## 学制说明

上海为五四学制，六年级（预备班）的名著书目与全国六三制七年级不完全相同，常涉及《童年》《鲁滨逊漂流记》一类作品。**判年级书目时以学校下发的实际书目为准，不要直接套用下表册次。**下表按统编六三制七至九年级排列，可作为主体参照；上海学生按学校要求平移对应。

## 复习法：一本一张卡

不做整本书摘抄，一本书只写四项：**三个必考情节 + 两个人物 + 一句主题 + 一个艺术特点**。名著题失分极少因为"没读过"，多因为"读过但记不住关键情节"。

## 七年级

### 《朝花夕拾》｜鲁迅｜散文集（10 篇）

- 必考篇目：《从百草园到三味书屋》《阿长与〈山海经〉》《藤野先生》《五猖会》《父亲的病》
- 人物：长妈妈（善良朴实、迷信，为"我"买《山海经》）、藤野先生（无民族偏见、严谨）、寿镜吾（方正质朴）、范爱农（正直孤傲）
- 主题：回忆童年与青年经历，批判封建教育、封建孝道与庸医
- 艺术：叙事中夹议论、白描、对比（百草园与三味书屋）
- 常考：《阿长与〈山海经〉》的欲扬先抑；《藤野先生》中"我"弃医从文的原因

### 《西游记》｜吴承恩｜明代神魔小说（100 回）

- 必考情节：大闹天宫、三打白骨精、真假美猴王、三借芭蕉扇、车迟国斗法
- 人物：孙悟空（反抗、机智、重情义）、唐僧（意志坚定但迂腐）、猪八戒（憨厚贪吃、爱占小便宜）、沙僧（忠厚老实）
- 主题：反抗与皈依、修心成佛
- 艺术：浪漫主义想象、幽默诙谐、人神妖三性合一
- 常考：孙悟空从"大闹天宫"到"取经成佛"的成长变化及原因

### 《骆驼祥子》｜老舍｜现代长篇小说

- 必考情节：三起三落（买第一辆车被大兵抢走；攒的钱被孙侦探敲诈；用虎妞的钱买车，虎妞难产死后卖车）
- 人物：祥子（由勤劳要强走向麻木堕落）、虎妞（泼辣、精明、占有欲强）、刘四爷、小福子、曹先生
- 主题：旧社会不让好人有出路
- 艺术：京味语言、细腻心理描写、景物烘托
- 常考：祥子悲剧的原因（社会原因与个人局限各占一半）

### 《海底两万里》｜儒勒·凡尔纳｜科幻小说

- 必考情节：海底森林狩猎、南极被困冰层、珊瑚王国葬友、大战章鱼、复仇击沉战舰
- 人物：尼摩船长（博学、神秘、反抗压迫）、阿龙纳斯（学者）、康塞尔（忠心、痴迷分类）、尼德·兰（捕鲸手、向往自由）
- 主题：科学幻想与反殖民压迫
- 艺术：科学性与想象力结合，细节可验证
- 常考：尼摩船长性格的两面性

## 八年级

### 《红星照耀中国》｜埃德加·斯诺｜纪实作品

- 必考内容：进入陕北苏区的过程、与毛泽东等领导人的访谈、红军长征、红小鬼
- 人物：毛泽东（质朴、博学、有幽默感）、周恩来（温和、有魅力）、彭德怀、朱德
- 主题：客观报道中国共产党与红军
- 艺术：纪实性、采访视角、人物刻画具体
- 常考：纪实作品"真实性"如何体现（采访对象、时间地点、原始材料）

### 《昆虫记》｜法布尔｜科普作品

- 必考对象：蝉、螳螂、蟋蟀、蜣螂、蜘蛛、蜜蜂
- 主题：科学观察精神与对生命的敬畏
- 艺术："以人性观虫性"，文学笔法写科学观察
- 常考：为什么说它既是科学著作又是文学著作

### 《经典常谈》｜朱自清｜学术随笔（13 篇）

- 内容：从《说文解字》讲到诗文，含《周易》《诗经》《史记》《诸子》等
- 主题：国学入门路径
- 艺术：通俗浅白、条理清晰、以史带论
- 常考：某一篇介绍的典籍常识；作者"普及经典"的写作意图

### 《钢铁是怎样炼成的》｜奥斯特洛夫斯基｜长篇小说

- 必考情节：救朱赫来、筑路、病榻上写作
- 人物：保尔·柯察金（坚韧、忘我）、朱赫来（引路人）、冬妮娅、丽达
- 主题：钢铁意志与为理想献身
- 常考："人最宝贵的是生命"一段的理解；保尔四次死里逃生

## 九年级

### 《艾青诗选》｜艾青｜诗集

- 必考篇目：《我爱这土地》《大堰河——我的保姆》《雪落在中国的土地上》《向太阳》《黎明的通知》
- 核心意象：土地（苦难与爱）、太阳（光明与希望）、火把、黎明
- 主题：深沉的爱国情感、对光明的追求、对苦难人民的同情
- 艺术：意象鲜明、散文化句式、忧郁而深沉
- 常考：土地与太阳两个意象的象征意义；诗歌的"忧郁"为何不等于消极

### 《水浒传》｜施耐庵｜章回体长篇小说

- 必考情节：林冲误入白虎堂→风雪山神庙→雪夜上梁山；武松景阳冈打虎→醉打蒋门神→血溅鸳鸯楼；鲁智深拳打镇关西→倒拔垂杨柳→大闹野猪林
- 人物：林冲（隐忍到反抗）、武松（刚烈、恩怨分明）、鲁智深（粗中有细、嫉恶如仇）、宋江（仗义但妥协）、吴用、李逵
- 主题：官逼民反
- 艺术：链式结构、人物个性鲜明、白话生动
- 常考：三个人物的情节与性格对应；"官逼民反"如何体现

### 《儒林外史》｜吴敬梓｜讽刺小说

- 必考情节：范进中举、周进撞号板、严监生临死伸两指、匡超人蜕变、王冕隐居
- 人物：范进（痴迷功名）、严监生（吝啬）、匡超人（堕落）、王冕（正面理想）
- 主题：批判科举制度与功名利禄对读书人的毒害
- 艺术：讽刺（夸张、对比、白描）、无贯穿全书的主角
- 常考：讽刺手法如何实现；为什么说它是"讽刺小说"而非"谴责小说"

### 《简·爱》｜夏洛蒂·勃朗特｜长篇小说

- 必考情节：盖茨海德府受辱、洛伍德学校、桑菲尔德相爱、婚礼中断后出走、重逢
- 人物：简·爱（自尊、独立、平等意识）、罗切斯特、里德太太、海伦、圣约翰
- 主题：人格平等与女性独立
- 常考："我们的精神是平等的"这句台词的内涵

## 名著题的五种问法

1. **情节梳理**：给出选段，问前因后果或补全情节链
2. **人物形象**：特征 + 原文依据（必须举情节，不能只写形容词）
3. **主题理解**：结合情节谈主题，忌背结论
4. **艺术特色**：结构、手法、语言任选其一，须举例
5. **综合探究**：比较两部作品、评价人物选择、联系现实

第 2 类占比最高。诊断时只看一条：**人物特征后面有没有跟一个具体情节。** 只有形容词的答案，通常是 0 分。
