# 文言文与古诗：知识框架与答题路径

## 一、先分课内课外

这一步决定后续所有做法，不能跳过。

- **课内**：一律回到教材注释、课后"思考探究"与"积累拓展"。课文原句是唯一标准，不另造解释，不引用与教材冲突的义项。
- **课外**：用三遍读法。
  1. 读通：圈生词，试断句，标出人名地名
  2. 读顺：补出省略的主语宾语，理清"谁做了什么"
  3. 读透：找议论句、抒情句，定主旨与人物品格

诊断时先问一句"这篇是课文里的吗"，答不上来的孩子往往是课外文言的失分大户。

### 上海卷的实际考法：课内外组合成一组题

2022 年起的变化：不再是"课内一段 + 课外一段"分两题，而是**甲（课内）+ 乙（课外）合成一组**，同组内依次考：加点字释义 → 词义辨析 → 翻译 → 内容理解 → 两文比较或评价。2025 年多区出现三篇组合（课内议论类 + 课外记叙类 + 说理类）。

区教研把命题方式概括为三种：**诗文外**（课内诗 + 课外文）、**文文外**（课内文 + 课外文）、**诗诗外**（课内诗 + 课外诗）。

对训练的直接影响有三条：

1. 该组最后一道比较/评价题，必须**两文各取一点 + 给出明确的比较结论（同或异）**，只答单篇不得满分。
2. 翻译题的得分点全部落在实词、活用、句式上；句子通顺但关键实词错，照样扣分。
3. 词义辨析选择题靠逐项回原句代入判断，不靠语感——这类题的正确率最能反映实词掌握的真实水平。

## 二、虚词：上海考纲只考 6 个

**上海考纲明确列出的虚词只有 6 个：之、其、而、以、何、于。**

这条直接决定文言复习的投入产出比：先把这 6 个的每种用法吃透，再考虑扩展。下表覆盖 20 个虚词，超出考纲的部分作为**阅读辅助**用——课外文言语段里会自然遇到，理解即可，不作为专项记忆任务。

每个虚词只需记住核心两三种用法，用课文原句作锚点。训练法是"一卡一词"：正面写义项，背面写课文原句，只认课文里的句子。

| 词 | 用法（配课文例句） |
|---|---|
| 之 | ① 助词"的"：水陆草木之花 ② 代词：下车引之 ③ 主谓之间取消独立：予独爱莲之出淤泥而不染 ④ 动词"到、往"：辍耕之垄上 ⑤ 宾语前置标志：何陋之有 |
| 其 | ① 他的/它的：择其善者而从之 ② 那：其船背稍夷 ③ 表反问"难道"：其真无马邪 ④ 表推测"大概"：其真不知马也 |
| 而 | ① 并列：中峨冠而多髯者 ② 承接：温故而知新 ③ 转折：人不知而不愠 ④ 修饰：面山而居 ⑤ 递进：饮少辄醉，而年又最高 |
| 以 | ① 用、拿：以刀劈狼首 ② 因为：不以物喜 ③ 用来：以光先帝遗德 ④ 认为：我以日始出时去人近 ⑤ 凭借：以我酌油知之 |
| 于 | ① 在：战于长勺 ② 到：达于汉阴 ③ 比：苛政猛于虎 ④ 被：困于心 ⑤ 向：告之于帝 |
| 为 | ① 做、担任：可以为师矣 ② 是：此为何若人 ③ 被：尽为所吞 ④ 为了：为宫室之美 ⑤ 替、给：为人谋而不忠乎 |
| 乃 | ① 于是：乃悟前狼假寐 ② 竟然：乃不知有汉 ③ 才：断其喉，尽其肉，乃去 |
| 则 | ① 就：学而不思则罔 ② 却：余则缊袍敝衣处其间 ③ 如果：入则无法家拂士 |
| 且 | ① 况且：且焉置土石 ② 将近：年且九十 ③ 尚且 |
| 虽 | ① 即使：虽人有百手 ② 虽然：虽我之死 |
| 因 | ① 于是：因屏人曰 ② 凭借：因势象形 |
| 遂 | 于是、就：遂迷，不复得路 |
| 者 | ① ……的人：择其善者而从之 ② 判断句标志：陈胜者，阳城人也 |
| 所 | ① ……的东西/地方：具言所闻 ② 与"为"构成被动：为……所…… |
| 焉 | ① 兼词"于此"：必有我师焉 ② 句末语气词 |
| 乎 | ① 吗：不亦说乎 ② 相当于"于"：在乎山水之间也 ③ 啊、呀 |
| 也 | 判断句标志；句中表停顿 |
| 何 | ① 什么：何陋之有 ② 为什么：何苦而不平 ③ 多么：水何澹澹 |
| 若 | ① 像：皆若空游无所依 ② 你：若为佣耕 ③ 如果 |
| 与 | ① 和：念无与为乐者 ② 给予 ③ 语气词"欤" |

训练法：不要背表格，改做"一卡一词"。正面写义项，背面写课文原句，只认课文里的句子。答题时先判断位置（在名词前还是动词前），再定义项。

## 三、实词：四类必考

**考纲范围是 150 个实词。** 2021 年起在 145 个基础上增加了 5 个双音节词：**阡陌、交通、问津、绝境、妻子**（均出自《桃花源记》）。复习时按考纲词表走，不要无限扩展——课外文言里遇到的生词按语境推断即可，不占记忆预算。

### 1. 一词多义（高频 12 组）

| 词 | 常见义项 |
|---|---|
| 故 | 旧的、原来的 / 所以 / 故意 / 缘故 |
| 顾 | 回头看 / 拜访 / 反而 / 顾念 |
| 举 | 举起 / 推举 / 全部 / 发动 |
| 绝 | 断绝 / 停止 / 极、非常 / 与世隔绝 |
| 期 | 约定 / 期限 / 希望 |
| 去 | 离开 / 距离 / 除掉 |
| 善 | 擅长 / 好的 / 友好 / 善于 |
| 少 | 年少 / 稍微 / 数量小 |
| 属 | 类 / 连接 / 同"嘱" |
| 亡 | 逃跑 / 丢失 / 死亡 / 同"无" |
| 许 | 答应 / 左右（数量）/ 处所 |
| 易 | 交换 / 容易 / 改变 |

### 2. 古今异义（二十组，答题时最容易按现代义硬套）

妻子（妻子儿女）、走（跑）、去（离开）、汤（热水）、涕（眼泪）、爪牙（得力助手）、卑鄙（身份低微、见识短浅）、感激（感动奋发）、开张（扩大）、痛恨（痛心遗憾）、往往（到处）、稍稍（渐渐）、无论（不要说）、可以（可以凭借）、其实（它的果实 / 那实际情况）、虽然（虽然如此）、牺牲（祭祀用的牲畜）、绝境（与世隔绝的地方）、鲜美（鲜艳美丽）、或（有的人）

判断法：把现代义代入原句读一遍，读不通就是古今异义。

### 3. 通假字（记形近与音同两类）

说—悦、女—汝、知—智、有—又、诎—屈、衡—横、简—拣、要—邀、具—俱、属—嘱、反—返、见—现、食—饲、邪—耶、惠—慧、亡—无、厝—措、畔—叛、曾—增、拂—弼

### 4. 词类活用

| 类型 | 判断方法 | 例 |
|---|---|---|
| 名词作动词 | 名词后带宾语，或前有副词 | 一狼洞其中（洞：打洞） |
| 名词作状语 | 名词直接修饰动词 | 其一犬坐于前（犬：像狗一样） |
| 形容词作名词 | 形容词处在主语或宾语位置 | 择其善者而从之（善者：优点） |
| 形容词作动词 | 形容词后带宾语 | 不知其能千里而食也（千里：日行千里） |
| 使动 | 主语使宾语产生该动作 | 无案牍之劳形（劳：使……劳累） |
| 意动 | 主语认为宾语如何 | 渔人甚异之（异：认为……奇异） |

## 四、特殊句式

| 句式 | 标志 | 例 |
|---|---|---|
| 判断句 | ……者，……也 / 乃、则、即、皆、为 | 陈胜者，阳城人也 |
| 被动句 | 为……所…… / 见 / 于 | 尽为所吞 |
| 省略句 | 省主语、宾语、介词 | （渔人）具答之 |
| 宾语前置 | 疑问代词作宾语、否定句代词宾语、"之"作标志 | 何陋之有 / 吾谁与归 |
| 状语后置 | "于""以"引导的介宾短语后置 | 战于长勺 |
| 定语后置 | "中心词+之+定语+者" | 马之千里者 |
| 主谓倒装 | 谓语提前表强调 | 甚矣，汝之不惠 |

## 五、翻译：六字诀

1. **留**：人名、地名、官名、年号、书名照抄
2. **删**：发语词、语气词、结构助词（如"夫""也""之"作助词时）
3. **换**：古今异义、通假字换成现代词
4. **调**：倒装句调回正常语序
5. **补**：补出省略的主语、宾语、介词
6. **贯**：意译贯通，语句通顺

评分点特征：一句翻译通常 2–4 个得分点，全部落在实词、活用、句式上。孩子翻完不对，先让他自己数"这句有几个得分点"，比直接给译文有效得多。

## 六、断句五法

1. 先找名词代词，定主语宾语
2. 再找动词，定谓语（一个谓语一段话）
3. 看虚词：曰、云、言后断；矣、也、乎、哉、焉、耳后断；而、则、以、于前不断
4. 看对称：对偶、排比句式，断在对称处
5. 看判断句："……者，……也"中间断

## 七、古诗鉴赏

### 1. 意象（先认意象，再谈情感）

| 意象 | 常见指向 |
|---|---|
| 月 | 思乡、怀人 |
| 柳 | 惜别、留恋 |
| 雁 | 思乡、书信、漂泊 |
| 舟 | 漂泊、羁旅 |
| 酒 | 愁绪、豪情、送别 |
| 梧桐 | 凄凉、孤寂 |
| 杜鹃 | 哀怨、思归 |
| 梅 / 菊 / 松竹 | 高洁、隐逸、坚贞 |
| 落日 | 苍茫、迟暮、思归 |
| 流水 | 时光流逝、愁思绵长 |
| 西楼 / 危栏 | 思念、愁苦 |
| 羌笛 / 胡笳 | 边塞、思乡 |
| 沙鸥 | 漂泊、孤寂 |

### 2. 手法（三层都要会认）

- 修辞：比喻、拟人、夸张、对偶、借代、设问、反问、双关、互文
- 表现手法：借景抒情、托物言志、虚实结合、动静结合、以动衬静、对比、衬托、用典、象征、渲染、白描、直抒胸臆、乐景写哀、以小见大
- 结构：起承转合、首尾照应、卒章显志

### 3. 情感（按题材归大类，比背几十个词有效）

思乡怀人、送别惜别、边塞征战（报国 / 厌战 / 思乡）、山水田园（闲适隐逸）、咏物言志、咏史怀古（昔盛今衰 / 借古讽今）、贬谪失意、忧国伤时、闺怨相思

### 4. 两类必考题型公式

**炼字题**：释字义（本义 + 句中义）→ 描景象（把这个字放回句子，写成一幅画面）→ 析效果（手法 + 情感或意境）
**名句赏析**：手法 + 画面 + 情感。三层齐全才拿满，只写"写得很美"不得分。

### 5. 默写

只错在字上，不在背上。做法：把易错字单独抄成一行，用"以义定形"解释为什么是这个偏旁，比反复抄整句有效。每次默写只查三类错：同音字、形近字、通假字。

## 八、诊断要点

文言文失分通常集中在四处，按出现频率排：

1. 实词按现代义硬套（占最多）
2. 翻译漏得分点，句子通顺但关键实词错
3. 断句靠语感，不看虚词标志
4. 诗歌只写情感词，不写手法与画面

第 1、2 项属于"知识性缺口"，需要补卡片；第 3、4 项属于"方法性缺口"，两三次定点训练能明显改善。诊断时必须分清这两类，否则会让孩子做大量无效抄写。
