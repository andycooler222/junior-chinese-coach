# 现代文阅读：题型公式与踩分点

## 通用答题骨架（任何题型都先走这四步）

1. **定题型**：圈题干关键词（"概括""赏析""作用""含义""分析"），题型决定公式。
2. **定区间**：回原文定位，答案永远在文本里，不在常识里。
3. **定层级**：按分值判点数。2 分答 1–2 点，3 分答 2–3 点，4 分答 2–4 点，5 分以上答 3–5 点。分值是最硬的提示，孩子不会答时先教他数分。
4. **定术语**：用学科词（铺垫、照应、烘托、卒章显志），不用口语（"写得很好""让人感动"）。

诊断时先看他卡在哪一步：不确定题型、找不到区间、点数不够、还是不会用术语。四种卡点训练方法完全不同。

## 一、记叙文（散文 / 小说）

### 1. 内容概括
公式：**谁 + 在什么情况下 + 做了什么 + 结果如何**
- 多事件题：按时间顺序分条，每条一句，句式统一（都用"人物+动作"）
- 踩分点：要素齐全、动词准确、不抄原文长句
- 常见错：把感受当情节（"他很感动"不是事件）

### 2. 词句赏析（最高频，也是最容易丢分的）
公式：**手法 + 写出了什么 + 效果 + 情感**
四层缺一层就扣一层分。

手法清单：
- 修辞：比喻、拟人、夸张、排比、反复、反问、设问、对比、借代、引用、双关
- 描写：动作、语言、神态、心理、外貌、细节、环境、正面、侧面
- 用词：动词的精准、叠词的韵律、色彩的冷暖

踩分点：
- "写出了什么"必须具体到内容，不能停在"生动形象"
- 效果要落到"突出了对象的什么特点"或"表达了人物什么心理"
- 情感层写"表现了作者/人物……的情感"

最常见错法：只写"运用比喻，生动形象"。这四个字单独出现基本不得分。

### 3. 句段作用（开头 / 中间 / 结尾）
公式：**结构作用 + 内容作用 + 情感或主题作用**。只答结构，通常只得一半分。

| 位置 | 结构作用 | 内容作用 |
|---|---|---|
| 开头 | 开篇点题、总领全文、设置悬念、引起下文、为下文作铺垫、奠定感情基调 | 交代背景、点明对象 |
| 中间 | 承上启下、照应前文、埋下伏笔、推动情节、转折 | 补充交代、丰富内容 |
| 结尾 | 总结全文、首尾呼应、卒章显志、留白 | 深化主题、升华情感、引人回味 |

答题时不是全抄表，而是先判断这段**实际承担了哪几条**，再逐条结合文本说明。

### 4. 句子含义理解
公式：**表层义（字面）+ 深层义（语境指向的人、事、理）+ 情感**
方法：抓关键词（可能是比喻义、象征义）→ 结合上下文语境 → 联系主旨。

区分：问"含义"答深层，问"赏析"答手法，问"作用"答结构+内容。三个词经常被孩子混着答。

### 5. 人物形象
公式：**性格特征（形容词）+ 依据（原文情节或描写）**
- 每个特征必须配一个证据，不举证的形容词不得分
- 特征要具体："节俭"优于"人很好"
- 近义特征合并计一点，不重复凑数

### 6. 标题作用
候选池（答 2–3 条即可，结合文本筛选）：
1. 是全文线索，贯穿始终
2. 概括主要事件或内容
3. 点明写作对象、时间、地点
4. 具有象征意义，揭示主旨
5. 设置悬念，吸引读者
6. 一语双关，含多层意思

常见错：把六条全抄一遍，不与文本对应。

### 7. 环境描写作用
- 自然环境：交代时地、渲染气氛、烘托心情、推动情节、暗示人物命运、深化主题
- 社会环境：交代时代背景、揭示社会关系或人物处境
公式：**本身作用 + 对人物 + 对情节 + 对主题**，按文本实际取舍。

### 8. 表现手法与探究题
- 表达方式五种：记叙、描写、说明、议论、抒情
- 表现手法：对比、衬托（正衬/反衬）、象征、欲扬先抑、以小见大、伏笔与照应、设置悬念、虚实结合、动静结合、正侧结合、借景抒情、托物言志
- 探究/开放题：**观点 + 文本依据 + 联系实际**，三段式。缺文本依据一律降档。
- 常见错：只谈自己看法，不回文本

## 二、说明文

1. **说明对象与特征**：看标题与首段定对象；特征从"是、能、可以、具有"这类判断句中提取，改写成短语。
2. **说明方法及作用**（十种）：
   - 举例子 → 具体真切
   - 列数字 → 准确具体
   - 作比较 → 突出强调
   - 打比方 → 生动形象
   - 分类别 → 条理清晰
   - 下定义 → 准确揭示本质
   - 作诠释 → 通俗解释
   - 摹状貌 → 形象可感
   - 画图表 → 直观明了
   - 引用 → 增强说服力或权威性
   公式：**方法 + 说明了对象的什么特征 + 效果词**
3. **说明顺序**：时间、空间、逻辑（由主到次、由因到果、由现象到本质、由概括到具体、由总到分）。
4. **语言准确性**（加点词能否删）：
   公式：**表态（不能删）+ 解释该词意思 + 说明删去后的变化 + 落脚到语言准确严密**
   变式：能否换成另一个词 → 表态 + 比较两词差异 + 原词更准确。
5. **代词指代与信息提取**：就近往前找，注意"这、此、其、该"。

## 三、议论文

1. **找中心论点**：看标题、开头、结尾；分论点归纳。论点必须是完整判断句，话题不是论点（"谈读书"是话题，"读书能塑造人的性格"才是论点）。
2. **论据类型**：事实论据（事例、数据、史实）、道理论据（名言、原理、定律）。判断标准看是否"用来证明观点"。
3. **论证方法及作用**：
   - 举例论证 → 具体有力
   - 道理论证 → 权威、有说服力
   - 对比论证 → 突出强调
   - 比喻论证 → 通俗易懂
   公式：**方法 + 论证了什么观点 + 效果**
4. **论证思路**：用"首先 / 接着 / 最后"串，每一段说清"提出了什么、用什么证明、得出什么"。不能只写"层层深入"。
5. **语言严密性**：抓"可能、往往、一般、主要"等限定词，答法与说明文一致。

---

## 四、非连续性文本

1. **信息提取与整合**：逐则材料列要点，同类合并，不同类并列。题目问"哪些方面"就分方面答。
2. **图表转述**：先看标题与图例，再看坐标轴含义，然后找趋势（上升/下降/波动）与极值（最高/最低），最后用数据作证。
3. **比较与建议**：每一条建议都要能对应到某则材料里的一个依据，做到"建议—依据"配对。
4. 常见错：把三则材料读成一则，答案全来自其中一则。

## 丢分点自检清单（十条）

按出现频率排序，诊断时逐条对照：

1. 不分点，一段写到底
2. 只答手法，不答效果
3. 抄原文长句，不概括
4. 写"生动形象"就停笔
5. 漏掉情感层
6. 4 分的题只答 1 点
7. 用口语，不用术语
8. 答非所问（问"作用"答成"内容"）
9. 套路全抄，不与文本对应
10. 开放题脱离文本

前四条属于"答题规范"，两三次训练就能改，属于性价比最高的提分点；后六条要靠针对性训练。

## 五、上海卷 2024–2025 高频新题型（专项）

以下五类在近两年各区一模二模中反复出现，且都有稳定的采分结构。它们是当前上海卷最值得投入的训练点，也是普通"答题公式"覆盖不到的部分。

### 1. 选材与组材（记叙文，3 分选择 + 8 分简答）

- **3 分选择题**："下列对选材和组材的分析不恰当的一项"。设错点两类：绝对化概括（出现"都、全部、始终、完全"）、顺序误判。做题方法：先把文中的几件事列成 1/2/3，再逐项回文本找反例，找到一个反例即可判错。
- **8 分简答题**："分析选材、组材的妙处"或"从组材与立意角度分析构思巧妙"。

四块采分点，缺一块按比例扣：

| 块 | 要写什么 |
|---|---|
| 选材 | 选了哪几件事/片段，共同指向什么情感或主题，为何典型 |
| 详略 | 哪件详写、哪件略写，为什么这样安排 |
| 组材顺序 | 按时间/空间/情感/认识推进，形成递进或对比 |
| 线索与落点 | 以某物、某句、某意象贯穿，最终扣回立意 |

要点：题干若有"与立意""表达感情"，每一点都必须回答"这样安排怎样把感情写深"，不能脱离情感谈结构技巧。

### 2. 词句表现力（4–6 分，四层递进）

公式：**释义 → 表层作用 → 深层含义 → 主旨回扣**

1. 释义：该词的本义与句中义
2. 表层：写出了当下什么情绪、状态
3. 深层：揭示什么性格、关系、对比或潜台词
4. 回扣：如何深化主旨、回应作者情感

与普通"赏析题"的区别：这里不问手法，问的是**这个词在语境里的表现力**，所以第三层"深层含义"是拉分点。只写到第二层，通常得一半分。

### 3. 心理/情感变化过程（结合加点词，常见 7 分）

典型设问："文中画线句体现了人物的内心变化过程，请结合上下文、结合加点词展开分析。"

答法：分阶段（变化前 — 转折触发点 — 变化后），每阶段三件套：**触发事件 + 心理状态 + 加点词的作用**，最后一句落到性格或主题。

只写"他很矛盾""他很痛苦"这类概括词，是 7 分题拿 2 分的典型原因。

### 4. 表格/结构图梳理（6–9 分）

把散落信息转成链条：情节—心理、现象—原因、观点—论据。

每空的写法固定为"**触发点 + 态度/状态（+ 指向对象）**"，用短句，前后逻辑要接得住（并列、递进、转折不能混）。失分多在只填情绪词、不填触发原因。

### 5. 段落互换 / 材料回归（说明文、议论文的拉分题）

- **段落能否互换**：同时给"结构关系"（总分、递进、时间先后、由主到次）与"内容逻辑"（前段提出什么、后段举例什么），两个理由缺一不可。
- **材料应放入哪一段**：材料指向什么 + 该段论点或说明对象是什么 + 两者如何对应，三点齐全。

共同点：**答案在"关系"上，不在"内容复述"上。** 只复述段落内容，通常得三分之一分。

### 6. 说明文/议论文的固定三题

- 说明文：筛选概括说明信息（含结构图填空）、说明方法及作用、说明语言准确性
- 议论文：把握论据（与论点匹配、论据作用）、论证思路与结构、论证语言严密性

这两类文体的失分很少在"读不懂"，多在"点数不足"和"没落到对象上"。诊断时先数点数，再看是否点明"说明了/论证了什么"。

### 7. 非连续性文本

多材料题必须"分则提取 → 找共同或差异 → 一句结论"。常见错法是把三则材料读成一则，答案全来自其中一则。
