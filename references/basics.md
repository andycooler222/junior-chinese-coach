# 基础知识：字词、病句、标点、修辞、文学常识

基础题的特点：**会就是会，不会就是不会，没有中间地带。** 所以它是最适合"定点补漏"的板块——不像阅读有方法空间，基础题只考记没记住、辨没辨清。

诊断方法：把最近三次卷子的基础题错项抄在一张纸上，按下面六类归堆。哪一堆超过三个，就攻哪一堆，一次只攻一堆。

---

## 一、字音字形

三类错法，训练方式完全不同：

| 类型 | 例子 | 训练法 |
|---|---|---|
| 多音字 | 差（chāi/chà/chā）、载（zài/zǎi）、塞（sāi/sè/sài） | 按词记，不按字记。一个音配两个词，读出声。 |
| 形近字 | 燥/躁/噪、籍/藉、概/慨、即/既 | 拆偏旁讲意义：火旁与干有关，足旁与动作有关。 |
| 易错笔顺与部件 | 冒（上为"冃"不是"日"）、虐、鼎 | 只在实际写错时纠正，不整篇抄写。 |

判断一个孩子是真不会还是粗心：让他**读**一遍而不是写一遍。读得对写错，是手的问题；读也读错，是记的问题。

## 二、成语误用（六类，占基础题错误最多）

| 类型 | 典型例 | 识别方法 |
|---|---|---|
| 望文生义 | 不刊之论（不可修改，非"不能刊登"）、万人空巷（人多，非"没人"）、差强人意（大体满意） | 逐字直译一遍，若结果荒谬，多半是望文生义 |
| 对象误用 | 豆蔻年华（少女）、相敬如宾（夫妻）、汗牛充栋（书多）、鳞次栉比（房屋） | 问"这个词只能用在谁身上" |
| 褒贬误用 | 无所不为、处心积虑、推波助澜、蠢蠢欲动 | 查感情色彩，不只查意思 |
| 重复赘余 | 忍俊不禁地笑了、津津乐道地说、妄自菲薄自己 | 看该词是否已含后面那个意思 |
| 谦敬错位 | 蓬荜生辉、抛砖引玉、鼎力相助、忝列 | 谦辞用于自己，敬辞用于对方 |
| 不合逻辑 | 当面锣对面鼓地"暗中"、莘莘学子们 | 看是否自相矛盾或叠床架屋 |

训练法：不背成语词典，改成"错例本"——只抄错过的那个句子，标出错在哪一类。同一类错三次以上，再集中讲这一类。

## 三、病句（六类）

### 判断顺序（压缩主干法）

1. 划出主干：主语 + 谓语 + 宾语
2. 查主干是否残缺、是否搭配
3. 查枝叶：定语、状语与中心语是否搭配
4. 查否定词数量（一个否定是否定，两个是肯定）
5. 查并列成分（"和、及、与"前后是否同类同级）
6. 查"是否、能否、好坏"这类两面词，后面是否只对应一面

### 六类速查

| 类型 | 常见标志 | 例 |
|---|---|---|
| 成分残缺 | 介词开头吞掉主语 | 通过这次活动，使我明白了……（删"通过"或"使"） |
| 搭配不当 | 动宾、主谓、修饰语与中心语 | 提高了……水平（对）／提高了……速度（错，应为加快） |
| 语序不当 | 多层定语状语顺序、关联词位置 | 他把这件事已经忘了（"已经"应在"把"前） |
| 结构混乱 | "原因是……造成的""本着……为原则" | 两种句式揉在一起，删一半 |
| 表意不明 | 代词指代不清、数量词修饰范围不清 | "几个学校的老师" |
| 不合逻辑 | 否定不当、两面对一面、分类不当 | 防止不发生事故（否定不当） |

答题规范：修改病句题要写"病因 + 改法"，只写改后句子通常扣分。

## 四、标点（五处高频）

1. **顿号与逗号**：并列词语用顿号，并列短语较长用逗号；并列成分后有"等、之类"时不再加顿号。
2. **分号**：只用于并列的分句之间；分句内已有逗号时才需要分号。
3. **冒号**：提示下文或总结上文；一个句子里不能连用两个冒号；冒号后一般管到句末。
4. **引号与句号的位置**：引文独立成句（前面有冒号），句号在引号内；引文作句子一部分，句号在引号外。
5. **省略号与"等"**：不能同时用（"……等"是重复）。

书名号只用于书名、篇名、报刊名、影视剧名，不用于课程名、活动名、产品名。

## 五、修辞及效果

| 修辞 | 效果关键词 |
|---|---|
| 比喻 | 生动形象，化抽象为具体 |
| 拟人 | 赋予人的情态动作，亲切可感 |
| 夸张 | 突出特征，强化情感 |
| 排比 | 增强语势，条理分明，节奏感强 |
| 反复 | 强调，强化节奏与情绪 |
| 对偶 | 形式整齐，音韵和谐 |
| 设问 | 引起注意，启发思考，引出下文 |
| 反问 | 加强语气，不容置疑 |
| 借代 | 简洁形象，突出特征 |
| 引用 | 增强说服力与文采 |

答"效果"时不能只写效果词，必须接"写出了什么"。这与阅读赏析题的要求一致。

## 六、文学常识

### 按时代串（记朝代不记年份）

| 时代 | 必须知道 |
|---|---|
| 先秦 | 《诗经》（最早的诗歌总集，风、雅、颂）、《论语》（语录体，儒家）、《孟子》《庄子》《左传》 |
| 汉代 | 《史记》司马迁，纪传体通史；乐府民歌 |
| 魏晋 | 曹操、陶渊明（田园诗）、王羲之《兰亭集序》 |
| 唐代 | 李白（诗仙）、杜甫（诗圣）、白居易、王维、刘禹锡、柳宗元、韩愈 |
| 宋代 | 苏轼、辛弃疾（豪放）、李清照（婉约）、欧阳修、范仲淹、王安石、陆游、周敦颐 |
| 元代 | 马致远（散曲）、关汉卿（杂剧） |
| 明清 | 罗贯中、施耐庵、吴承恩、曹雪芹、蒲松龄、吴敬梓、龚自珍 |
| 现代 | 鲁迅、老舍、朱自清、茅盾、巴金、冰心、艾青、闻一多 |

必背一个组合：**唐宋八大家**——韩愈、柳宗元、欧阳修、苏洵、苏轼、苏辙、王安石、曾巩。

### 易混三组

- 《左传》编年体 vs 《史记》纪传体 vs 《资治通鉴》编年体
- 豪放派（苏辛）vs 婉约派（柳永、李清照）
- 鲁迅的散文集《朝花夕拾》vs 散文诗集《野草》vs 小说集《呐喊》《彷徨》

## 七、综合运用

| 题型 | 结构 |
|---|---|
| 口语交际（劝说、邀请、转述） | 称呼 + 目的 + 理由（两条）+ 礼貌收尾 |
| 材料探究 | 分则提取 → 找共同点或差异 → 一句结论 |
| 活动设计 | 主题 + 形式 + 步骤（三步以内） |
| 拟写标语 / 开场白 | 扣主题 + 有节奏 + 不超字数 |

最容易丢分的是口语交际：只写目的不写理由，或漏掉称呼与礼貌用语。答题时按"要素清单"逐项打勾，比自由发挥稳。
