# 初中语文学习教练 · junior-chinese-coach

一个用于初中语文诊断与训练的 Agent Skill（适配 WorkBuddy / 支持 SKILL.md 规范的 Agent 环境）。

面向**上海五四学制、统编版六至九年级**，把"语文差"这种模糊判断拆成可定位、可训练、可验证的能力点。核心流程是 **诊断 → 定位 → 训练 → 复测**，不是讲题，也不是代写。

## 它解决什么问题

多数语文辅导工具在做两件事：讲题、代写。这两件事都不改变孩子的能力。本技能做的是第三件事：**先定位失分落在哪个能力点上，再只攻这一个点**。

四条铁律写死在 `SKILL.md` 里，任何情况下不得违反：

1. **不代写、不代答。** 不输出成品句子、范文、可直接抄的答案，禁止"可以改为：……"这类句式。
2. **一次只攻一个能力点。** 不同时改结构又改语言。
3. **结论必须落到能力点。** 禁止"要加强积累""多读多写"这类无法执行的话。
4. **每个判断给依据。** 指出原文哪一句、答案哪个踩分点、评分哪个维度。

## 怎么用

直接说场景即可，技能通过描述里的触发词自动命中：

| 说法 | 走的流程 |
|---|---|
| "这是他这次月考的卷子，帮我看看问题在哪" | A 试卷诊断 |
| "这道赏析题他答的，为什么只得 1 分" | B 阅读单题突破 |
| "这篇作文帮我改"（贴全文） | D 三遍改法 |
| "《水浒传》考点帮我理一份" | 名著考点卡 |
| "默写老是错字，怎么练" | 基础知识 |
| "出一张诊断单打印" | 诊断单模板 |

也可以点名或走斜杠命令：

```
/junior-chinese-coach 看看这份卷子
用初中语文学习教练，家长模式，走 A 流程
```

身份可指定 **孩子模式**（默认，只提问引导）或 **家长模式**（出诊断结论 + 追问脚本）。

## 两个设计取舍

**按能力点归类，不按题号。** 一张卷子错 8 道题，可能只对应 3 个能力点。按题号讲等于讲 8 遍，按能力点讲只讲 3 遍。

**提分按"失分 × 改得快"排，不按"哪里最差"。** 家长最常见的误判是把"阅读理解不深"当成首要问题，实际孩子先丢的是答题规范和审题——这两项一两次训练就能改。

## 关于数据准确性

- 卷面分值（古诗文约 35、现代文约 35、综合运用 20、写作 60）取自 2022 年起的上海中考框架，**每年会有微调，以当年真题与考试院说明为准**。技能内已注明不得向学生宣称精确数字。
- 2021 年及以前的结构不同（默写 16 分、综合运用约 12 分），技能内保留了对照表，用于识别旧版资料。
- 名著书目已核实为上海 14 本，六年级为《童年》《鲁滨逊漂流记》，仍以学校下发书单为准。
- 文言例句均取自统编教材课文，未使用课外生造例句。
- 命题规律文件中所有结论按 A/B/C 三级标注可信度，C 级（机构预测类，如"2027 改分层赋分"）明确标注未见官方文件，不得作为评分依据。
